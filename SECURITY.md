# Security and privacy

This repository is a public case-study documentation bundle. It contains original explanations and links to a static, fictional-data portfolio prototype. Production application source remains private.

## Separation from production

- No production customer records, prospect contacts, private notes, exports, or database snapshots belong here.
- No credentials, tokens, environment files, connection strings, privileged links, or operational configuration belong here.
- No private backend modules or production API contracts are included.
- The prototype must not connect to production APIs, authentication, databases, scheduled jobs, collection sources, or outreach providers.
- Prototype controls only change fictional, disposable browser state. They cannot discover real leads, contact anyone, or update business records.
- Public website links are navigation links. The prototype does not submit a real quote request or exercise the business's form.

## Safe contributions

Create fictional examples from scratch. Do not export real data and attempt to sanitize it. Review screenshots and artwork for incidental private information. Keep security explanations abstract enough to avoid exposing operational access or deployment details.

Only business results explicitly approved for publication belong in the case study. Owner-reported results must keep that label and must remain separate from demonstration statistics.

If a contribution appears to contain sensitive information, do not include it in an issue or public pull request. Remove it from the proposed public artifact and arrange a private maintainer review before publication.
